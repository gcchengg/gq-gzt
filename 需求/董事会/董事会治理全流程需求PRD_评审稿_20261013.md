# 董事会治理全流程需求产品需求文档（评审稿）

> 评审版本：V0.1（待评审）  
> 日期：2026年10月13日  
> 适用角色：集团董办、一汽股权、董事  
> 涉及模块：董事聘任、履职准备、履职计划、履职任务、履职报告、董事专项任务、履职建议

## 1. 需求背景

董事会治理流程涉及集团董办、一汽股权多个经办岗位、董事及各履职事项责任人。目前需围绕董事推荐函下发、聘任手续、履职手册确认与更新、履职计划制定和执行、履职报告发送、专项任务及履职建议落实，建立前后衔接的任务流转。各环节需明确办理角色、办理页面、提交条件及后续触发事项，使经办人能够从工作台待办进入对应办理页面，完成后驱动下一环节。

本需求以用户提供的流程描述为业务规则，并结合项目现有 `boardGovernance` 页面和路由整理。项目当前为前端演示工作台，若涉及钉钉、跨角色待办通知及持久化联动，需由开发评审确认后端与消息能力的实现范围。

## 2. 目标与范围

### 2.1 目标

1. 建立集团董办、一汽股权、董事三类角色参与的董事聘任与履职闭环。
2. 每项任务明确接收角色、办理入口、提交动作及后续触发结果。
3. 董事履职计划、计划执行结果、专项任务和履职建议能够归集到董事履职记录及报告。
4. 支持履职报告按选择的接收人员发送，并形成发送完成状态。

### 2.2 本次范围

- 董事推荐函下发及一汽股权聘任任务
- 董事履职手册确认、资料更新、手册推送
- 年度履职计划制定、董事确认、年度计划生成及任务执行
- 履职写实报告编辑与发送
- 董事专项任务下发、安排与完成情况确认
- 董事履职建议发起、董办分派、责任人落实
- 工作台待办入口、角色范围及对应页面跳转

### 2.3 角色定义

| 一级角色 | 参与岗位/用户 | 本需求中的职责 |
|---|---|---|
| 集团董办 | 集团董办人员 | 下发董事推荐函；发起董事专项任务；作为履职报告可选接收方 |
| 一汽股权 | 办公室、人力、数字化、董办，以及履职事项责任人 | 办理聘任及履职准备事项；制定计划、组织执行；分派和落实建议；编辑履职报告 |
| 董事 | 对应董事本人 | 确认年度履职计划；填报和发送本人履职写实报告；发起履职建议 |

> 一汽股权下各岗位是否使用独立登录身份，或由“一汽股权”角色通过岗位/责任人筛选模拟，需评审确认。项目现有工作台以一级角色切换和责任人字段模拟部分岗位视角。

## 3. 业务流程总览

```text
集团董办下发推荐函
  → 一汽股权办理董事简历、系统权限、工商变更
  → 董办确认履职手册
  → 责任人更新手册资料并提交
  → 董办预览并推送手册，同时发起履职计划制定
  → 一汽股权制定年度履职计划
  → 董事确认计划
  → 一汽股权生成年度计划并创建履职任务
  → 各责任人办理并提交履职任务
  → 通知相关安排人员；董事和董办完善履职报告并发送

并行业务：
集团董办下发董事专项任务 → 一汽股权/董事安排与办理 → 完成情况归集至履职报告
董事提交履职建议 → 一汽股权董办分派责任部门/责任人 → 责任人落实并提交
```

## 4. 详细需求

### 4.1 董事推荐函下发与聘任办理

**入口页面：** `/boardGovernance/appointment`（董事聘任）

1. 集团董办在页面点击“下发董事推荐函”，录入或确认推荐函信息后下发。
2. 下发成功后：
   - 向一汽股权对应办公司人员推送钉钉消息，提示董事推荐函已下发。
   - 在一汽股权工作台“董事聘任”Tab/待办中创建董事简历、系统权限配置、工商变更三项任务，并分派到对应岗位/责任人。
3. 一汽股权相关经办人从工作台点击各自任务“去执行”，进入对应办理页面，填写本项内容并提交。
4. 三项任务均提交后，触发“履职准备”中的“履职手册确认”任务，由一汽股权董办办理。
5. 页面显示聘任相关任务状态与办理进度；提交后应反映到工作台对应待办。

| 任务 | 接收岗位（按当前需求描述） | 当前项目页面/入口参考 |
|---|---|---|
| 董事简历 | 人力 | `/boardGovernance/home` → 董事聘任 → 去执行 |
| 系统权限配置 | 数字化 | `/boardGovernance/home` → 董事聘任 → 去执行 |
| 工商变更 | 董办 | `/boardGovernance/home` → 董事聘任 → 去执行 |

办公室作为一汽股权下的岗位，是否在聘任阶段接收上述任务、承担统筹或只接收消息，待确认。

### 4.2 履职手册确认、资料更新与推送

**手册确认办理页：** `/boardGovernance/preparation/directors/D-02?tab=handbook`  
**资料更新办理页：** `/boardGovernance/duty-tasks?taskType=material&department=综合管理部-办公室`

1. 一汽股权董办在“履职准备”Tab的“履职手册确认”任务中点击“去执行”，进入手册确认页面。
2. 点击“定期发起资料更新”后，系统按手册目录中的责任部门/责任人生成资料更新任务，并通知对应责任人。责任人从“履职准备”Tab进入任务，补充资料并提交。
3. 仅当所有本次涉及的责任人均已提交后，手册资料表状态更新为“已提交”。未全部提交时应能识别仍未提交的资料/责任人；提示形式待评审确认。
4. 当手册表内相关资料状态均为“已提交”时，董办可点击“预览并推送手册”。在弹窗点击“确认推送”后：
   - 完成履职手册推送；
   - 自动发起履职计划制定；
   - 跳转工作台首页并定位履职计划制定任务；
   - 向一汽股权董办创建履职计划制定待办。
5. 若资料未全部提交，“预览并推送手册”不得进入确认推送流程。具体按钮禁用或点击后提示，待产品/开发评审确认。

### 4.3 履职计划制定及董事确认

**一汽股权计划制定页：** `/boardGovernance/preparation/directors/D-02?tab=annual-plan&planMode=planning`  
**董事计划确认页：** `/boardGovernance/duty-tasks?taskType=annual-plan-confirmation&bizId=ANNUAL-D-08`

1. 一汽股权董办从“履职计划制定”任务进入计划制定页面，新增年度履职计划明细并提交。
2. 提交后，向对应董事角色创建“履职计划制定/确认”任务。
3. 董事点击“去执行”进入确认页面，选择计划并提交。
4. 董事提交后，向一汽股权董办推送钉钉消息，提示董事已完成履职计划制定。
5. 董事确认结果应回写至相应年度计划。后续由一汽股权角色进入工作台“履职计划制定”区域的“年度履职计划生成”Tab，点击“生成年度计划并创建任务”。

### 4.4 年度计划生成与履职任务执行

1. 一汽股权经办人在“年度履职计划生成”Tab点击“生成年度计划并创建任务”。
2. 系统弹出“年度履职计划选择”抽屉，经办人选择计划明细并提交。
3. 系统按所选计划明细向对应负责人创建“履职任务管理”任务。
4. 负责人从 `/boardGovernance/home` 的“履职任务管理”进入任务，点击“去执行”，跳转至对应办理页，例如：`/boardGovernance/duty-tasks?bizId=PLAN-001`，填写详细信息并提交。
5. 当所有对应负责人均提交后：
   - 钉钉通知董事本人、综合董办、综合办公室，提示完成差旅、日程等相关安排；
   - 向一汽股权董办与董事角色创建“履职报告完善”任务。
6. 所有责任人的提交状态应可汇总判断，以作为后续通知和报告完善任务的触发条件。

### 4.5 履职报告完善与发送

**一汽股权董办报告示例：** `/boardGovernance/management/D-01?tab=reports&reportType=年度报告`  
**董事报告示例：** `/boardGovernance/management/D-01?tab=reports&reportType=月度报告`

1. 一汽股权董办和董事分别从各自工作台中的“履职报告完善”任务点击“去执行”，进入对应董事、报告类型的履职写实报告页面。
2. 用户可编辑履职写实报告。
3. 页面右下角提供“确认发送”按钮。点击后弹出确认窗口，用户选择接收人员，可包括集团董办、领导班子等，支持按需求选择后确认。
4. 确认后完成报告发送，并更新该报告的发送状态。
5. 报告接收人范围、可选人员树及董办/董事是否使用相同的报告编辑权限，待确认。

### 4.6 董事专项任务

**入口页面：** `/boardGovernance/director-special-tasks`

1. 集团董办点击“董事专项任务”，弹出创建任务窗口。
2. 窗口字段如下：

| 字段 | 规则 |
|---|---|
| 任务名称 | 填写任务名称 |
| 人员范围 | 从管理范围内董事中选择，可多选 |
| 工作分类 | 下拉单选：董事会、调研、子企业重要会议、能力培训、专项交流、督导子企业落实工作、解决子企业发展问题、其他 |
| 时间 | 填写任务时间 |
| 地点 | 填写任务地点 |
| 工作内容 | 填写工作内容 |
| 预期达成目标 | 填写预期目标 |
| 相关材料 | 支持上传相关附件 |

3. 点击“确认下发”后，任务发送至一汽股权综合管理部董办、办公室及董事本人，用于开展日程等相关安排，并进行任务完成情况确认。
4. 任务完成情况同步至董事履职报告。
5. 相关接收人员同时收到“履职计划制定任务”。该任务名称与专项任务办理/安排任务之间的关系需评审确认（见待确认问题）。

### 4.7 履职建议与落实

**董事入口：** `/boardGovernance/duty-suggestions`  
**董办分派页：** `/boardGovernance/duty-suggestions/SUG-002`  
**责任人办理页：** `/boardGovernance/duty-suggestions/SUG-001?assignee=陈哲`

1. 董事在“履职建议”菜单发起建议，并关联一项前序履职任务。
2. 建议提交后发送至一汽股权角色。
3. 一汽股权董办在工作台“履职建议落实”Tab/分组收到任务，进入建议详情，指定责任部门、责任人等信息并下发。
4. 对应责任人收到“履职建议落实”任务，进入责任人办理页填写落实内容并提交。
5. 建议与前序履职任务保持关联，落实结果可供履职过程及报告查看。
6. 责任部门、责任人之外是否需要填写期限、办理方案、结果附件或董办验收，按项目现有页面能力与本次用户描述不完全一致，待确认是否纳入本次需求范围。

## 7. 待确认

1. **一汽股权聘任任务岗位映射：** 用户描述明确三项任务由人力、数字化、董办办理，同时列出办公室为一汽股权下第四小角色。办公室在聘任阶段是否接收任务、承担统筹，或只参与后续手册资料更新/专项任务安排？项目已有 mock 的工商变更办理部门与当前描述也不完全一致，请确认最终岗位归属。
2. **董事专项任务触发的任务名称：** 专项任务下发后，接收人需处理日程安排等工作；描述同时称其收到“履职计划制定任务”。是否确为该任务名称，还是应为独立的“专项任务安排/办理”任务？
3. **履职建议责任人提交后的闭环：** 是否由责任人提交即完成，还是需一汽股权董办确认后才完成？是否要求期限、办理方案及附件？
4. **钉钉通知范围与消息内容：** 已明确的通知节点按正文记录；请确认通知发送到具体人员、群/组织还是个人，以及系统待办是否与钉钉消息同时创建。若先按现有描述执行，可保持 recipient 为对应岗位/责任人，不在 PRD 中增加更细分的渠道规则。
5. **报告接收人员范围：** “集团董办、领导班子等”是否由通讯录/组织树选择？一汽股权董办与董事是否可以选择相同接收范围？
6. **手册资料提交条件：** “所有对应责任人都提交”是指本次更新目录中所有资料/责任人均提交，还是仅当前董事相关资料？项目中的资料任务按部门组织，请确认判断范围。

## 8. 验收要点

1. 集团董办可从董事聘任页下发推荐函；一汽股权对应人员收到消息和三项待办，且每项待办可进入正确办理页。
2. 三项聘任任务全部提交后，董办可在履职准备中收到手册确认任务。
3. 发起手册更新后，责任人可通过指定任务页补充并提交资料；全部完成后手册资料显示“已提交”。
4. 手册资料未全部提交时不可完成推送；全部提交并确认推送后，系统生成履职计划制定任务并跳转至工作台对应任务。
5. 一汽股权提交年度履职计划后，董事收到确认任务；董事提交后董办收到钉钉通知。
6. 一汽股权生成年度计划后，对应负责人收到履职任务；负责人全部提交后，系统发送安排通知并生成董事和董办的报告完善任务。
7. 董事与一汽股权董办可编辑履职报告，选择接收人员并确认发送；报告显示发送完成。
8. 集团董办可创建专项任务并多选董事；确认下发后，指定一汽股权岗位和董事收到任务，完成情况可在履职报告中查看。
9. 董事可关联前序履职任务发起建议；一汽股权董办可分派责任人；对应责任人可办理并提交结果。
10. 工作台中的任务状态与各办理页面提交结果一致；用户从待办进入的是与任务类型相符的页面。
