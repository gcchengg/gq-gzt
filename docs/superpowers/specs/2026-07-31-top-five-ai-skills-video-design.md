# Top 5 AI Skill 高端教程视频设计

## 1. 项目目标

制作一条 9:16 竖屏知识教程视频，面向 AI 初学者和普通职场人，深入讲解五个常用 Skill 主题。视频强调每项能力解决什么问题、如何使用、输入与输出分别是什么，以及使用时需要注意什么。

预计时长约 5 分 35 秒。旁白、字幕、示例任务及逐幕画面以 [`skill-video/top-5-skills-video-script-v3.md`](../../../skill-video/top-5-skills-video-script-v3.md) 的 V3 版本为内容基线。

## 2. 内容范围

视频聚焦以下五个主题：

1. `find-skills`
2. `tavily-search`
3. `summarize`
4. `skill-creator`
5. PDF、Word、Excel 文档三件套
其中“文档三件套”代表能力类别，不在视频中承诺具体产品名称、安装地址或未经核验的性能指标。`memory-setup`、`self-improving-agent`、`code-simplifier`、AI PPT 专家和会议纪要不属于第一期范围，可作为后续选题。

## 3. 已确认的创意方向

### 3.1 视觉定位

采用“暗色 AI 产品界面 × 信息可视化”，不使用人物、漫画形象、故事角色或虚拟主持人。

视觉系统：

- 背景：深黑、蓝黑和墨绿色渐变。
- 主强调色：青绿色，用于正常状态、流程连接和成功反馈。
- 辅助色：蓝色用于来源与信息，橙红色仅用于风险、错误和重点提醒。
- 界面：统一的圆角、细描边、微弱辉光、网格背景和模块标题栏。
- 字体：中文使用清晰的现代无衬线粗体，英文及数字使用几何无衬线或等宽字体。
- 质感：克制、专业、清晰，避免游戏 HUD、过量霓虹和无意义装饰。

### 3.2 动画语言

动画必须服务于教程表达：

- 光标输入表现任务如何进入 Skill。
- 关键词拆解表现系统如何理解需求。
- 节点连接和数据流表现处理步骤。
- 扫描、进度和状态变化表现执行过程。
- 面板展开和字段抽取表现结构化结果。
- 左右对比表现使用前后的效率与质量变化。
- 章节切换使用镜头缩放、模块重排和同构匹配转场。

禁止使用：

- 人物或漫画角色。
- 随机粒子爆炸、无意义镜头抖动和频繁故障闪烁。
- 与旁白无关的装饰动画。
- 难以阅读的密集小字和虚假产品截图。

## 4. 叙事结构

1. 开场钩子：普通聊天能力无法完成实时搜索、长文提炼和文件处理。
2. `find-skills`：从需求到候选 Skill、对比和安装。
3. `tavily-search`：实时搜索、多来源整理和引用核验。
4. `summarize`：按受众与目的提炼长内容，并保留原文定位。
5. `skill-creator`：把重复步骤封装为可复用流程。
6. 文档三件套：串联 PDF 提取、Word 汇总和 Excel 分析。
7. 结尾：五个模块汇入统一 AI 工作台，并提出评论问题。

每个 Skill 使用同一讲解节奏：

> 真实痛点 → 核心作用 → 使用方式 → 输入示例 → 处理过程 → 输出结果 → 注意事项

## 5. 场景设计

共 7 幕：

- Scene 01：开场钩子，20 秒。
- Scene 02：`find-skills`，60 秒。
- Scene 03：`tavily-search`，60 秒。
- Scene 04：`summarize`，60 秒。
- Scene 05：`skill-creator`，60 秒。
- Scene 06：文档三件套，60 秒。
- Scene 07：总结与互动，15 秒。

完整旁白、屏幕字幕、示例任务和每幕动画细节均以已批准的 V3 文稿为准，不在实现阶段擅自改写。

## 6. 音频与字幕

- 旁白语言：中文普通话。
- 语速：教程型中速，保证专业名词清晰可辨。
- 字幕：每次最多两行，以语义短句分段，不能遮挡核心界面。
- 背景音乐：低干扰的未来感电子氛围音乐。
- 音效：只用于输入、匹配、扫描、成功、警告和章节转场。
- 旁白优先级最高，背景音乐和音效必须自动压低。

## 7. 制作结构

视频应采用可复用的模块化场景：

- `SkillFrame`：统一编号、标题、状态和进度。
- `PromptInput`：任务输入与关键词拆解。
- `ProcessFlow`：节点、连线和执行状态。
- `ResultPanel`：结果卡、引用、统计或文件输出。
- `BeforeAfter`：使用前后对比。
- `ChapterTransition`：章节编号和模块重排。
- `CaptionTrack`：逐句字幕。

每个 Skill 只替换内容和必要的专属处理动画，共享视觉变量与基础动效，以保证五分多钟的统一性。

## 8. 验收标准

### 内容

- 五个主题全部出现，顺序与 V3 文稿一致。
- 旁白内容不被擅自改写。
- 每个 Skill 必须包含痛点、作用、使用方式、具体示例、输出和注意事项。
- 不把能力类别错误包装成具体可安装产品。

### 视觉

- 全片没有人物、漫画形象或虚拟主持人。
- 暗色 AI 产品界面统一，文字在手机尺寸下清晰可读。
- 动画能够解释处理逻辑，不只是卡片进出场。
- 每个一分钟章节至少包含四次清晰的信息阶段变化，但不制造无意义快切。

### 技术

- 画幅为 1080×1920，30fps。
- 总时长与批准的音频和字幕时间轴一致。
- 无黑帧、无截断字幕、无重叠面板、无缺失音轨。
- 最终交付高质量 MP4，并保留可继续修改的工程文件。

## 9. 审核门禁

正式制作按以下顺序确认：

1. 设计与 V3 文稿确认。
2. 关键风格帧确认。
3. 完整分镜或低清动态预览确认。
4. 配音与字幕时间轴确认。
5. 成片预览确认。
6. 高质量 MP4 渲染与技术验收。

任何上游内容发生变化后，相应的后续预览需要重新确认。
