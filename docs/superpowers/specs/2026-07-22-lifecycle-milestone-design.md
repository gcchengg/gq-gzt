# 生命周期重要事项板块设计

## 目标

在参股公司报告“一、基础底数‘清’”中新增“5. 生命周期重要事项”，用符合现有报告视觉的时间轴事件卡片展示截图中的事项，并允许用户在报告配置弹窗中独立控制该板块是否显示。

## 展示位置与配置

- 在 `sectionOptions` 的 `base` 分组末尾新增“生命周期重要事项”。
- 新增板块配置键为 `base-4`，默认跟随现有全选逻辑选中。
- 板块放在“4. 对标情况”之后、“二、财务状况‘清’”之前。

## 数据来源标注

板块标题使用项目现有 `SourceMark` 说明图标模式。用户悬停图标时显示：

`取数来源：投后报告-列入生命周期时间轴事项`

页面不直接平铺展示数据来源文字。

## 内容

示例事件包含以下字段：

- 日期：2026-06-24
- 类别：三会管理
- 事项：接收长春一东临时董事会议题（选举独立董事、选举董事、接收国有资本预算金）并完成审批
- 其他相关方：无

不显示截图中的“列入生命周期轴事项”标签，也不显示表格序号。

## 视觉与布局

采用单条时间轴事件卡片，不使用表格：

- 左侧为时间节点区域，以月份和日期形成视觉锚点。
- 右侧为事件内容区域，顶部显示“三会管理”类别标签，主体突出事项文本，底部显示其他相关方。
- 卡片沿用当前报告的蓝灰色、细边框、轻阴影和红色强调色。
- 移动端改为上下布局，日期置于内容上方。
- 打印和 PDF 预览时整张卡片避免跨页断开。

## 数据组织

示例数据作为结构化对象维护在 `src/pages/companyList/data.js` 中，字段为 `key`、`date`、`category`、`content`、`relatedParty`。页面从该对象渲染，便于后续替换为接口数据或扩展为多条事项。

## 验证

- 静态回归检查确认 `base-4` 已加入配置并按条件渲染。
- 检查标题来源说明图标及四项示例内容。
- 检查不包含生命周期标签和表格结构。
- 运行 Biome 检查、`git diff --check` 和 Vite 生产构建。
