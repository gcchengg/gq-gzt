# newSanhui2 议题提报股权投委会字段设计

## 范围

仅修改 `/newSanhui2` 的“议题提报 → 议题清单”新增、编辑抽屉，不修改 `/newSanhui`。

## 表单与数据

- 在“分类与审批”区域的“审批层级”下方增加“是否为股权投委会”单选项。
- 新增和编辑议题时均显示该字段。
- 使用 `topicType` 保存：`"1"` 表示“是”，`"0"` 表示“否”。
- 新增议题默认选择“是”。
- 编辑旧数据时优先回显已有值；缺少 `topicType` 时默认选择“是”。
- 保存时 `topicType` 随议题对象进入议题清单数据。
