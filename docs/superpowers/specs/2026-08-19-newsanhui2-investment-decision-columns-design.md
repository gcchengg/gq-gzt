# newSanhui2 股权投委会决策结果列设计

## 范围

仅修改 `/newSanhui2` 的“决策执行 → 决策情况”表格，不修改 `/newSanhui`。

## 表格设计

- 议题名称根据 `topicType === "1"` 显示“股权投委会”Tag。
- 在“一汽股权决策结果”右侧新增“股权投委会决策结果”分组。
- 新分组包含董事会、监事会、股东会 / 投委会三列。
- 投委会结果使用 `investmentBodPassFlag`、`investmentBosPassFlag`、`investmentShPassFlag` 独立字段。
- 当 `topicType === "1"` 时显示投委会结果；否则三列统一显示 `--`。

## 一致性与保存

- 一致性仍只比较“一汽股权决策结果”和“三会决议”。
- 股权投委会决策结果不参与一致性判断。
- 原因说明校验和保存行为保持不变，新字段随原有行数据一并保存。

- 执行 V2 测试、代码检查和 Vite 生产构建。
