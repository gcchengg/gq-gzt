# FAW Equity PRD brand style

## Source

Visual authority: `assets/reference/一企一策工作台优化方案20260709.pptx`.

## Exact tokens

| Role | Value |
| --- | --- |
| Primary / FAW blue | `#152A8C` |
| Emphasis / FAW red | `#C00000` |
| Body text | `#344054` |
| Muted text | `#667085` |
| Pale blue fill | `#EAF0FF` |
| Light neutral fill | `#F7F9FC` |
| Chinese font | Prefer `Microsoft YaHei` / `微软雅黑`; use `Arial Unicode MS` only when the runtime lacks Microsoft YaHei |

## Page system

- Use A4 portrait for Chinese PRD documents.
- Use approximately 2.2 cm left/right margins and 1.8 cm top margin.
- Place the authentic FAW Equity logo in the upper-right header.
- Use a restrained footer with document type and page number.

## Title hierarchy

- Cover title: 24 pt, bold, FAW blue.
- Add a FAW-blue rule below the cover title.
- Heading 1: 16 pt, bold, FAW blue, with a thin blue bottom rule.
- Heading 2: 13 pt, bold, FAW blue.
- Heading 3: 11.5 pt, bold, FAW blue.
- Body: 10.5 pt, `#344054`, 1.35 line spacing.

## Red usage

Use FAW red only for:

- risk or exception emphasis;
- reject/return operations;
- confirmation warnings;
- a small cover accent.

Do not use red for ordinary headings or decorative blocks.

## Icons and images

- Prefer authentic assets under `assets/icons/`.
- Keep title icons monochrome blue when used.
- Preserve screenshot aspect ratio.
- Center screenshots and add short captions in muted text.
- Never fabricate business screenshots, company logos, or interface evidence.

## Tables

- Header fill: FAW blue with white bold text.
- Alternate body rows: white and `#F7F9FC`.
- Vertically center cell text.
- Use compact columns for sequence, date, state, or terminal; allocate width to narrative fields.
- Allow rows to expand; never set fixed row heights.
